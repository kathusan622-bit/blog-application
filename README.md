# BlogSpace - Blog Application (Module 01: Frontend Development)

A responsive Blog Application website built with **HTML, CSS and JavaScript**. It works on mobile phones, tablets and desktops.

## Pages
| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section and list of all blogs |
| Login | `login.html` | Login with email and password |
| Register | `register.html` | Create a new account with validation |
| Dashboard | `dashboard.html` | See stats and manage (delete) your blogs |
| Create Blog | `create-blog.html` | Write and publish a new blog |

## Features
- Mobile-first responsive design (media queries + CSS Grid/Flexbox)
- Hamburger menu on mobile
- Form validation using JavaScript
- Data saved in the browser using `localStorage` (no backend)
- Protected pages: Dashboard and Create Blog need login

## Tech Stack
HTML5, CSS3, JavaScript (ES6)

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right click `index.html` and choose **Open with Live Server** (or just double-click the file).
